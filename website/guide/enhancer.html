FrameLab se všemi funkcemi: instalace enhanceru

Dva ZIPy a jeden průvodce. Nic nekompiluješ, neinstaluješ Python ani SDK a nehledáš složky pro DLL. Hlavní FrameLab už obsahuje frame generation, dvě herní ukázky, český překlad včetně modelu, exportér a podporu NR. Externí NR soubory doplní průvodce.

NR je komunitní experiment. Ověřený veřejný instalační balík DLSS 5 NR přímo od NVIDIA k 19. 11. 2026 není dostupný. Níže uvedený druhý ZIP poskytuje Veyra, nikoli NVIDIA ani FrameLab. ShortFuse je upravený NVIDIA runtime. Práva k použití a redistribuci těchto souborů zde nejsou potvrzena; odkaz ani import je neuděluje. Tuto cestu použij, pokud k souborům máš příslušné oprávnění. Vyjádření NVIDIA · Původ a podmínky komponent Veyry.

1. Stáhni a rozbal FrameLab

  1. Stáhnout FrameLab preview.11 pro Windows x64. Přesná velikost je na stránce stahování.
  2. Pravé tlačítko na ZIP → Extrahovat vše → nová složka například na Ploše. Nepracuj uvnitř ZIPu. Počítej přibližně se 4 GB volného místa pro oba stažené archivy, rozbalení a import.
  3. Otevři 1 - Spustit FrameLab.cmd. V kartě Vstup vyzkoušej CS:GO nebo Spider-Mana. Frame generation i titulky lze používat hned, NR ještě čeká na externí soubory. Pro OCR může Windows vyžadovat doinstalování anglického rozpoznávání textu; postup je v základním návodu.

2. Stáhni přesný externí balík

  • Externí download: Veyra-2.1.9-NVIDIA-win64-portable.zip — 731 MB.
  • Stránka vydání autora a seznam souborů. Když přímý odkaz nefunguje, otevři Assets a najdi přesně uvedené jméno.
  • Nepoužívej AMD, Source code ani variantu s dodatkem Virtual Camera. Průvodce přijímá pouze tento ověřený archiv. ZIP nerozbaluj a Veyru nemusíš spouštět.
  • Tento download není na našem serveru. Oficiální NVIDIA DLSS download nyní obsahuje jiné technologie DLSS; libovolné nvngx_dlss.dll, nvngx_dlssd.dll nebo nvngx_dlssg.dll tento NR soubor nenahradí.

3. Průvodce vše zkopíruje

  1. Ukonči FrameLab. Ve složce FrameLabu otevři 4 - Doplnit enhancer.cmd. Stejný průvodce jde otevřít přes AI / NR → Doplnit / zkontrolovat enhancer; před importem pak FrameLab zavři.
  2. Klikni 2 - Vybrat stažený ZIP a doplnit soubory a vyber stažený Veyra-2.1.9-NVIDIA-win64-portable.zip.
  3. Počkej na Soubory jsou připravené. Kontroluje se SHA-256 celého ZIPu i obou DLL; při chybě se žádný neověřený soubor neinstaluje. Licence a původ se přenesou spolu se soubory. Neinstaluje se ovladač ani systémová služba a není potřeba administrátor.
  4. Znovu otevři 1 - Spustit FrameLab.cmd, přejdi do AI / NR a zapni Zapnout enhancer (F6). Pokud se GPU inicializace nepovede, enhancer se vypne a ukáže konkrétní chybu; původní obraz zůstane dostupný.

4. První porovnání

  • Začni limitem 720p, silou 65 % a Děleným porovnáním. Dělicí čáru posouvej posuvníkem. F8 zmrazí stejný snímek, F7 přepíná původní / upravený / dělený obraz, F6 efekt vypne.
  • V Runtime / diagnostika je výchozí ShortFuse NR 310.9.16, komunitní varianta ověřená zde na RTX 4050 Laptop. Řady RTX 20/30/50 nejsou tímto testem potvrzené. NVIDIA NR 310.8 original je určená pro RTX 50 a v tomto vydání nebyla na takové kartě otestovaná.
  • Při zapnutém frame genu platí vstup → frame gen → enhancer → české titulky → monitor. Původní obraz v NR porovnání znamená snímek před enhancerem, tedy případně už generovaný. Pomalé AI může snížit počet zobrazených snímků a zvýšit latenci.
  • Skutečné porovnání před / po s posuvnou lištou. Změna pixelů není automaticky lepší obraz; kontroluj obličeje, HUD a rychlý pohyb.

Když se něco nepovede

ProblémCo udělat
Nemám kartu AI / NRMáš preview.10 nebo starší build bez podpory NR. Stáhni celý preview.11; samotné přidání DLL do preview.10 nestačí.
Kontrolní součet nesouhlasíStáhni přesný NVIDIA ZIP 2.1.9 bez dodatku. Zkontroluj dokončené stahování. Průvodce úmyslně nepřijímá neznámé verze.
Soubor se používá / přístup odepřenUkonči všechny své instance FrameLabu a zkus import znovu. Celá složka musí být zapisovatelná.
Průvodce je zablokovaný správcemNeměň zásady počítače. Se souhlasem správce rozbal přesný externí ZIP a použij ruční cesty níže.
Model nejde inicializovatOvěř NVIDIA ovladač a profil. Zkus 360p/540p, uvolni paměť GPU a začni s FG 2×. Konkrétní chybu najdeš v AI / NR a app/nr-cache/nr-host.log.
Stažení Veyry už není dostupnéPoužij vlastní dříve získaný ověřený ZIP, pokud k němu máš oprávnění. Bez kompatibilního runtime NR nefunguje; zbytek FrameLabu dál ano. Neověřené DLL z náhodných webů nejsou náhrada.

Ruční import pro správce: z kořene rozbalené Veyry zkopíruj runtime/experimental/nr-ampere/nvngx_dlssnr.dll do FrameLab/app/runtime/nr-sf/nvngx_dlssnr.dll a runtime/experimental/nr-original/nvngx_dlssnr.dll do FrameLab/app/runtime/nr-original/nvngx_dlssnr.dll. Zachovej původní licenční soubory z licenses pod FrameLab/app/licenses/nr-external. Nezaměňuj tyto DLL za přibalený app/nr-host/nvngx.dll: ten je malý adaptér FrameLabu, nikoli AI model ani ovladač NVIDIA.
