FRAME/LAB · WINDOWS · PREVIEW.12

From download to your first Czech subtitle.

Illustrated guide for FrameLab preview.14. Original Windows 11 installation steps are supplemented by actual exports of the new interface. Numbers and arrows are a separate layer.

Preview.14 bundles neural OCR and adds reading time and sentence joining. Q5 is available without a quality or speed benchmark. Installation and some unchanged controls use labelled historical images; OCR settings show preview.14. External NR files remain separate.

01 / 12

Download complete FrameLab

Open the FrameLab website and choose Download complete FrameLab. Use the windows-x64-full.zip package.

Download preview.14 ↓

Windows 10/11 x64, NVIDIA GPU and an up-to-date driver. Allow about 4 GB for the base app and NR import. Optional CUNI models require additional space as listed in the subtitle guide. NVIDIA VFG requires RTX 40/50.

Expected result: The complete FrameLab ZIP is in your downloads folder. GitHub Source code is not a ready-to-run application.

02 / 12

Right-click → Extract all

In Windows, right-click the downloaded FrameLab ZIP and choose Extract all….

Do not run the program inside the archive. Double-clicking a ZIP does not extract it.

Expected result: The destination-folder dialog opens.

03 / 12

Choose a short path and wait

Use Browse… to select a new Desktop folder, for example FrameLab. Confirm Extract and wait for extraction to finish completely.

Avoid a deeply nested path. Error 0x80010135 means the path is too long: cancel extraction and repeat it in a shorter location.

Expected result: The extracted FrameLab folder contains app, deps, docs, tools, licenses and launchers. Keep everything.

04 / 12

Launch the first demo

Open the extracted FrameLab folder and double-click 1 - Spustit FrameLab.cmd.

No Python, pip, SDK or compiler installation is required. The runtime and CPU translator are bundled. The app starts in English; use EN / CZ for Czech. The application is unsigned; disabling Windows protections is not required.

Expected result: A short CS:GO clip loops. If AI / NR reports missing files, continue with step 7.

05 / 12

Try both games

At the bottom of Capture / Vstup, use CS:GO 1080p or Spider-Man 540p to switch bundled videos.

No capture card or further download is needed. The Vyzkoušet titulky EN > CZ button runs the translation test used below.

Expected result: Both videos play directly from the application folder.

06 / 12

Enable frame generation

Open Frame gen, choose NVIDIA VFG (RTX 40/50) and enable Frame generation. Start with Medium / Střední and 2×.

Alternatively use 2 - NVIDIA RTX 40-50.cmd. Optical Flow is an alternative backend, not a second stacked effect. 3× and 4× may increase ghosting and latency.

Expected result: The status says NVIDIA VFG active. The generated-frame counter updates.

07 / 12

Download external enhancer files

Close FrameLab. Open 4 - Doplnit enhancer.cmd in its folder. The first wizard button opens the exact external archive.

Veyra 2.1.9 NVIDIA portable — 731 MB ↓

Keep this ZIP compressed. You do not need to run Veyra. This is a community experiment; rights to use and redistribute these NR DLLs have not been established here. Linking/importing does not grant a license. Source and terms.

Expected result: You have exactly Veyra-2.1.9-NVIDIA-win64-portable.zip. AMD, Virtual Camera and Source code variants are not accepted.

08 / 12

Select the ZIP and finish import

In the same wizard, click 2 — Vybrat stažený ZIP a doplnit soubory. Locate the downloaded archive, select it and click Open / Otevřít.

Wait for verification and copying. No manual DLL placement or driver installation is needed. A checksum error means the archive is incomplete or different.

Expected result: The wizard says Soubory jsou připravené (Files are ready). Close it and restart FrameLab.

09 / 12

Enable NR and compare the same frame

Open AI / NR → Enable enhancer. Start with 65%, Split comparison and the 720p cap in Quality and performance. Initial model loading may take a while.

F8 freezes the matching pair; drag the divider in the preview or use its slider. F7 switches views and F6 toggles the effect. The tested RTX 4050 used the default ShortFuse NR profile. The original NVIDIA profile targets RTX 50 and was not tested here.

Input → selected frame generation → NR → Czech overlay → monitor. The NR original may already be a generated frame. Reduce the AI cap to 540p/360p if performance is low.

Expected result: You see ORIGINAL and ENHANCED labels, a divider and the enabled checkbox. A visible change is not always an improvement.

10 / 12

Enable local Czech subtitles

Open Subtitles. Keep RapidOCR / PP-OCRv5 English. Its runtime and models are included; no Windows component installation is needed.

Select the included CPU model or optional CUNI Q3/Q5/Q8. The app downloads and verifies CUNI and, on first use, its portable runtime. Enable translation and select only the English dialogue strip.

Place Czech above/below the original or enable overlay dragging. Text and its black background stay inside the visible image, including multiline captions, crop and fullscreen. Complete model and placement guide →

Expected result: Try the artificial subtitle clip under Capture. A better translation model does not repair misread OCR.

11 / 12

Connect a real game through capture

Connect console / second PC → capture-card HDMI input → USB/PCIe to the FrameLab PC. Close other applications using the card.

In Capture / Vstup, choose your card and driver-reported resolution/FPS. Begin with automatic or supported 1080p mode. Click Start capture / Spustit vstup. Select output and volume in Audio / Zvuk.

No capture card was attached to this laptop; the screenshot shows control locations with its ACER camera listed. Live HDMI capture and audio were not verified in this walkthrough. HDR is not implemented.

Expected result: Your source appears in the preview. For a black image check the signal, cable, driver and whether another app is using the card.

12 / 12

Choose a monitor and go fullscreen

In Display / Zobrazení, choose image scaling and monitor. F11 opens the main image fullscreen; Escape returns. Comparison views, controls and the OCR outline hide automatically. The cursor hides after 2 idle seconds. Detailed illustrated fullscreen guide →.

Watch the processed output in FrameLab. To use a TV, connect it to this PC’s GPU output. Capture-card HDMI passthrough does not include FrameLab effects.

Set the actual monitor resolution and refresh rate in Windows; FrameLab does not change them with this selector.

Expected result: You are viewing the processed application output. Press Escape to return to the controls.

Verified: Explorer extraction to a short path, both clips, NVIDIA VFG 2×, graphical-wizard import and NR + local OCR/Czech translation on RTX 4050 Laptop. No physical capture card was attached. Game imagery retains its owners’ rights; see bundled licenses and sample provenance.
