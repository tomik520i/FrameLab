01 / 20

Download and extract the full ZIP

Download preview.18 ↓

On Windows 10/11 x64, right-click the ZIP → Extract all. Choose a short writable path such as D:/FrameLab and wait for completion. Do not run inside the ZIP.

Install your NVIDIA GPU driver, and your capture-card driver for live input. No Python, compiler or SDK setup is needed. For error 0x80010135, use a shorter path.

Expected result: A complete folder with app, deps, docs, tools, licenses and launchers.

02 / 20

Launch the app and a demo

Run Start FrameLab.cmd or 1 - Spustit FrameLab.cmd. A clean install starts the GTA demo; subsequent launches restore the session. EN / CZ is at the top right.

Under Capture, choose GTA 720p / 30 FPS, CS:GO 1080p or the EN → Czech test at any time. No capture card is needed. These screenshots show a playing clip or the explicitly labelled artificial OCR fixture.

Expected result: Preview on the left, settings on the right. Small arrows beside the tabs reveal more tabs.

03 / 20

Connect a capture card

HDMI source → capture-card input → USB/PCIe to the PC. Close other apps holding the card. In Capture, select device, resolution and FPS separately, then Start capture. 4K and other aspect ratios depend on driver modes.

Delivered frames reports received frame dimensions. The API does not report HDMI timing. A 60 FPS capture can repeat a 30 FPS game image. Test 30 FPS is synthetic. For No Signal, check the cable, source and device ownership.

Expected result: Live input replaces the demo. HDR is not implemented.

04 / 20

Open your own video or MKV

Capture → Open video… opens a file picker. Use pause, seek and loop. The full package includes LibVLC codecs; no system VLC installation is required.

If the file contains multiple audio/subtitle tracks, select them after loading. Disable embedded subtitles if unwanted. OCR reads visible text; it does not translate text tracks directly or transcribe speech. Protected streaming files are unsupported.

Expected result: The file name and native dimensions appear. Missing track selectors can mean the file has no such tracks.

05 / 20

Start with 2× frame generation

In Frame gen, choose RIFE 4.22 lite / DirectML, D3D11 Optical Flow or NVIDIA VFG. Start at 2×. Try RIFE Low on RTX 4050; use Optical Flow on the tested Intel UHD. RIFE models are bundled.

RIFE needs suitable DirectX 12 hardware; Optical Flow uses Direct3D 11. AMD and older GeForce have not been physically tested. VFG remains RTX 40/50; NR has separate limits. GPU matrix and measurements →

Expected result: An active backend status and generated-frame counter during motion.

06 / 20

Optionally install the enhancer

FG and OCR work without this step. NR is a community experiment using external files. Close FrameLab and run 4 - Doplnit enhancer.cmd. The wizard links to the exact package and verifies the import.

Download Veyra-2.1.9-NVIDIA-win64-portable.zip, keep it zipped and select it with the second wizard button. Do not choose AMD, Virtual Camera or Source code. Exact links, terms and troubleshooting →

Expected result: The wizard confirms files are ready. Restart the app afterwards.

07 / 20

Enhancer, comparison and optional Eco

NR is blocked on unsupported hardware. This step does not bring DLSS to AMD, Intel or GTX. External NR DLLs are not bundled or mirrored.

Enable the enhancer in AI / NR. Start with 720p / 1 pass. F6 toggles the effect, F7 switches comparison, F8 freezes a matching pair. Strength changes the final blend; reducing it alone does not reduce AI computation.

Eco: enhance before frame gen moves NR before FG. At 30 → 60 FPS, NR can process about 30 rather than 60 images per second. It can add latency, uses extra VRAM and changes artifacts. It is optional and off by default.

Lower AI caps or fewer passes reduce work in both modes. Output dimensions are preserved. Measured Eco results and limits →

Expected result: AI status and evaluations per second. A change is not necessarily an improvement; compare the same scene.

08 / 20

Choose languages, OCR and a translation model

In Subtitles, choose the language in the picture and the target. RapidOCR / PP-OCRv5 multilingual includes all 12 packs. OPUS-MT / CPU works immediately for EN → CS; optional CUNI Q3/Q5/Q8 retain that same pair.

For other languages choose TranslateGemma 4B Q4_K_M, click Download / resume and verify, and wait. Then enable Translate subtitles. Q4 is 2.49 GB; first GPU runtime adds 1.62 GB. Q8 and 12B are larger untested options. Memory, languages and limits →

Expected result: A ready model and a caption in the chosen language. First loading can take tens of seconds. Small Gemma makes mistakes, especially in Czech.

09 / 20

Mark one word and the reading area

Wait for a legible English caption. Click Select subtitle word + reading area…. Drag around one complete word in the preview.

Then choose Adjust reading area and mark a band large enough for longer, multiline captions. Exclude minimaps, plates and chat. The word supplies approximate colour and letter height; it is not a required phrase or font name. Confirm Use this style.

Expected result: A blue sample and a larger yellow region. Background playback continues.

10 / 20

Inspect what OCR actually accepted

OCR inspector / saved sample… reopens the saved sample. Expand Recognized text / measured values / reasons.

Inspect text, colour, height and rejection reasons. Accepted lines are green; text outside the region is marked orange. If valid captions disappear, select a cleaner word or adjust tolerances under Appearance details. Unrelated text with the same style inside the region can still pass.

Expected result: In this artificial example, the sentence was accepted and the timer outside the region rejected.

11 / 20

Save a profile for a game or video

Under Subtitle appearance, choose Save as…, enter a name and click Save profile. Select it from the list next time. Save changes updates the selected profile; Save as creates a new one.

Style and reading region are saved. The selection survives restarts. Check the profile after changing source resolution or subtitle style.

Expected result: Your name appears in the profile selector.

12 / 20

Allow reading time and place the overlay

Minimum on screen starts when Czech appears. Keep while waiting retains the last caption while another translates. Join split sentences attempts to join continuations; disable it if unrelated dialogue is joined.

Below, adjust size, placement and anchors, or enable Drag Czech overlay in preview. Multiline text is centered and clamped to the visible image. The green OCR rectangle marks source reading, not Czech placement.

Expected result: The translation remains readable; translation delay is not eliminated.

13 / 20

Choose monitor and scaling

Display → Fit preserves the whole image. Fill and oversized 1:1 can crop edges. Choose the output monitor. Set its resolution and refresh rate in Windows, not here.

The processed image goes through this PC’s GPU output. Capture-card passthrough does not contain FrameLab effects. F11 shows clean output; Escape/F11 returns to controls.

Expected result: The intended monitor and aspect ratio.

14 / 20

Choose audio output

Use the right tab arrow to reach Audio. Select the Windows output, volume and mute. File and capture audio have their own controls.

Not every clip contains sound. For a movie with multiple audio tracks, choose its language track in the player. FG and NR add video delay; the APP counter does not measure A/V synchronization.

Expected result: Sound reaches the chosen device when the source contains audio.

15 / 20

Record 15 seconds for comparison

In Recording → Choose folder…, select a drive with space. For 1440p with all stages, allow at least 36 GiB free as a practical recommendation. Click Record 15 s analysis and wait for clip export too.

Exports include RAW, generated frames, matching before/after enhancement, final image with Czech captions, SRT, timing and settings/ID JSON. Only enabled effects are recorded; clips are silent. Incomplete takes are labelled. Format and limits →

Expected result: Completed exports in Clips folder. Do not change the pipeline during a take.

16 / 20

Read FPS and latency correctly

Stats separates incoming frames, estimated changing content, submitted images and Windows-confirmed IDs. Dashes mean unavailable, not zero. Confirmed IDs can be a lower bound.

APP / callback → Present measures time inside the app. It excludes the capture card, physical display and controller. GPU usage covers the whole card, including other apps. One screenshot does not establish sustained FPS.

Expected result: Graphs with explicitly scoped measurements.

17 / 20

Enable debug and text logging

Use the tab arrow to open Debug & measurement. Choose duration, optionally Frame-by-frame timing and Include OCR and translated text. Click Start debug recording or F9.

Until stopped writes until Stop/F9 or exit. If you close with logging active, a normal next launch restores it. Logs contain timestamps, settings, CPU/GPU, FPS, queues, OCR and translations according to selected options. No images or audio are recorded and nothing uploads automatically. Check private text before sharing.

Expected result: Elapsed time and log size increase. Open debug folder opens files; Stop ends writing.

18 / 20

Small statistics while playing

In Debug, enable Fullscreen FPS + latency or press F10. Then F11 opens clean output. Small FPS, APP and P95 readouts remain in the upper-right corner.

F10 hides the statistics. Controls, comparisons and the OCR reading outline hide in fullscreen; translated captions remain. Statistics are not burned into analysis clips.

Expected result: Clean output with an optional small readout; Escape returns to settings.

Game window, Remote Play and subtitles only

Capture → Application window: refresh and select the game. For captions alone, enable the transparent overlay over the source window. Set the OCR region and translated text position separately. Local models remain available; the paid API is optional with your own key.

Choose translation compute and GPU

Subtitles → Local / offline → CUNI or Gemma → Translation compute. Auto uses NVIDIA CUDA here; Vulkan supports other suitable GPUs, or use CPU / RAM. Translation GPU is independent of image GPU. Changes disable translation; enable it again to load the new choice.

Memory, options and measured timing →

Expected result: Status reports the actual backend and memory placement.
