FRAME/LAB · PREVIEW.12 · FULLSCREEN

Configure in the app. View it fullscreen.

F11 automatically shows one final image: source → selected frame generation → enabled enhancer → Czech subtitles. Comparisons, panels, labels and the OCR outline hide themselves. There is nothing to turn off manually.

01 / 04

Configure the output first

Start a demo or capture input. Choose the backend and multiplier in Frame gen, enable the enhancer and strength in AI / NR, and configure the reading region and Czech text in Subtitles.

For inspection choose Split comparison, drag its divider and optionally freeze with F8. Comparison is for the settings window. F11 automatically hides it and resumes a frozen image, preserving effect strength and enabled features.

02 / 04

Choose monitor and scaling

Open Display (use the arrows beside the tabs if hidden). Choose the target Monitor; the window moves there.

  • Fit / show whole image: recommended starting point, with black bars if needed.
  • Fill / crop edges: fills the display and may crop the HUD.
  • 1:1 / source pixels: small sources stay small; larger sources may exceed the screen.

Set monitor resolution and Hz in Windows. Window size only changes the window; fullscreen fills the target monitor. A TV must connect to this PC’s GPU. Capture-card HDMI passthrough does not carry FrameLab effects.

03 / 04

Press F11. That is all.

Press F11 or click Fullscreen (F11). Maximizing a Windows window is different.

You get one final image with enabled effects and subtitles. NR split lines, RAW/FG/RAW comparison, controls, counters, labels and the OCR guide disappear automatically, regardless of the selected window comparison.

The cursor over fullscreen hides after 2 idle seconds. Move it to show it again. The source game HUD and other applications’ external overlays are not hidden by FrameLab.

04 / 04

Esc or F11 returns to settings

Press Esc or F11 again. The window returns with the previously selected comparison available. Change settings as needed, then press F11 again.

F1 toggles the dashboard only in windowed mode. It never shows panels over fullscreen. F7/F8 are window comparison controls, so there is no need to find them in fullscreen.

If the right panel is missing after returning, it was hidden earlier with F1; press F1 in the window to restore it. To disable the enhancer itself, uncheck it or set strength to 0%.
