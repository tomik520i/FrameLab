Your own AI server for subtitles

Included in the complete preview.19 package. A custom AI server is optional; local translators and OpenAI remain available.

What this is for

OCR runs on the FrameLab PC. Recognized text goes to the address you configure; the selected model translates it on that server. This can be another LAN computer or your own local server. No image or audio is sent. Local models and OpenAI remain separate options.

1. Prepare the server

Load a model on the server and run a compatible API: OpenAI-compatible Chat Completions (for example llama.cpp / LM Studio) or Ollama. Its address must be reachable from the FrameLab PC. FrameLab does not install or reconfigure the server. localhost always means this computer.

2. Connect FrameLab

Open Subtitles → Translation provider → Custom AI server / LAN. Select the server protocol. For OpenAI-compatible, for example enter http://192.168.1.100:8080/v1; for Ollama, http://192.168.1.100:11434. Use the base address, not the full /chat/completions path. Do not embed credentials, query parameters or fragments.

3. Choose the model and optional key

Click Connect / refresh models and select Server model. If the server does not expose a list, enter the exact ID manually, including any path. A key is optional; leave it blank for an unauthenticated server. It is stored in Windows Credential Manager for that address only. Your OpenAI key is never automatically forwarded to a custom server.

4. Configure languages and translation

Select source subtitle language, target language and OCR region, then enable subtitle translation. Language quality depends on the server model; FrameLab’s language list does not guarantee that model’s competence. Re-enable translation after changing the endpoint, model or parameters.

5. Optional parameters

Temperature is sent only when enabled. Additional JSON parameters must be supported by your exact server and model. The following example worked on the tested llama.cpp server; it is not a universal configuration. Ollama uses an options object. Bound output and timeout; subtitles usually do not need long reasoning.

{"chat_template_kwargs":{"enable_thinking":false},"reasoning_budget":0}

6. Conversation memory

Use recent dialogue adds bounded source history. Remember important dialogue is a further experimental option: the same model on your server selects original lines to retain longer. It defaults off and does not identify characters. Translation specialists or weaker models can perform worse; CUNI does not support this builder. Expand the context panel to inspect what the last translation actually received.

Troubleshooting

Network error: check address, server reachability and firewall. HTTP error: check model, key and supported parameters. Incomplete answer or thinking instead of translation: disable reasoning using your model’s supported configuration or adjust the limit. FrameLab does not display tool calls or reasoning as captions and does not automatically retry failed API calls. Memory-generation errors fall back to recent original dialogue, with status visible in settings.

Preview.20: vlastní překladový prompt

Otevři Titulky → Custom AI server / LAN → Upravit překladový prompt… a zaškrtni Použít vlastní prompt. Editor platí jen pro vlastní server.

Použij {source_language} a {target_language}. FrameLab připojí aktuální OCR a zapnutou historii původních replik automaticky. Výběr paměti má samostatný prompt.

Vyber Prostý text nebo <translation>...</translation>. Režim značek doplní pokyn k formátu a zobrazí text uvnitř právě jednoho úplného bloku. Chybné značky způsobí přeskočení odpovědi.

Načíst ukázku je výchozí bod, ne změřené zlepšení kvality. Obnovit výchozí vypne vlastní instrukce. Uložit a použít uloží nastavení, znovu připojí aktivní překladač a vymaže historii; Zrušit zahodí rozepsané změny.

Preview.20: Nejdelší čekání na titulek (sekundy) a Tokenů na odpověď mají v čisté instalaci hodnoty 2 sekundy / 1000 tokenů. Čas platí pro všechny repliky titulku. Po timeoutu se pokračuje nejnovějším titulkem bez běžného restartu workeru a mazání historie. Více výstupních tokenů nezvětšuje kontext modelu ani nezaručuje včasnou odpověď.
