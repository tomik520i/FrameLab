Conversation memory for subtitles

Included in preview.19. An optional experiment, off by default. First compare the same part of your game with memory on and off.

1. Start with ordinary translation

Choose the source, restrict OCR to subtitles, select source/target languages and verify translation with memory off. Use a local model, OpenAI with your own key or a custom AI server. The model must support the chosen language. OPUS is a fixed EN→CS translator and does not use these LLM context options.

2. Enable recent history

In Subtitles, select Use recent dialogue. Re-enable translation after changing settings if needed. Bounded recent original lines and their timing are included in the request. Previously translated answers are not fed back. This does not reliably identify characters or genders.

3. Optionally retain important dialogue

With recent history enabled, a supported model also offers Remember important dialogue (experimental). That same selected model chooses original lines in the background for retention up to ten minutes. No second model prepares its context. CUNI does not support this second option. TranslateGemma can accept it but is a translation specialist: improvement is not guaranteed. Start with it off for specialized translators.

4. Inspect what the model actually received

Expand Context used for the last translation. Check whether it matches the current conversation. If a meaning gets stuck after a topic change, stop translation and enable it again to clear memory. Start with empty memory when changing games. A failed long-memory selection falls back to recent lines and reports the state in settings.

Benefits, cost and failures

Across 75 diagnostic situations, correct displayed captions rose from 59.6 to 72.0% for Luna and from 56.4 to 75.6% for the LAN Gemma. Topic changes themselves did not improve. Memory may increase latency, API cost and local model load. The tested Gemma ran on a separate RTX 3090, not beside frame generation on the laptop. This is a controlled diagnostic set reviewed by Codex, not general accuracy across games.

Privacy

With a local model, processing remains local. With OpenAI or a custom server, enabled memory sends selected previous OCR text along with the current line. This feature does not send images or audio. Credentials are not included in the package; each user supplies their own.
