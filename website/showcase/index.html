NO CLOUD TRANSLATION

Teach it the subtitle style.

  1. Draw the area where subtitles can appear.
  2. Select one clear word to learn its color and glyph size.
  3. Save a named profile and load it next time.

These archived Czech takes used CUNI Q5. Preview.17 also offers TranslateGemma for other languages; download models in Subtitles. OCR packs and EN → CS CPU translation are bundled.
