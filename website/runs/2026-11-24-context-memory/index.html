Memory needs rules

Context can fix meaning

With Luna, “license” in a flying conversation changes from a driving licence to a pilot licence. The timestamped variant also correctly renders “Are you mad?” as asking about anger.

CUNI can repeat old lines

In this test, broader history made CUNI worse. The timestamped transcript reduced some failures but did not beat its standalone translation. A bigger prompt alone is not a fix.

Known gender is not speaker recognition

In 12 controlled examples, the character profile was supplied in advance. Better gender agreement shows use of this information, not automatic recognition of real game speakers. The gameplay export lacks reliable labels.

A large Gemma on another computer

The external Gemma 4 runs on a server RTX 3090, with a 214,272-token context and roughly 22 GB VRAM occupied at inspection. The test sends a short history. This is a separate optional setup.

Same inputs, four memory strategies

Scores cover 59 assessable game jobs. Gender is a separate test of 12 labelled scenes. Latency is the full request, with live OCR, FG and enhancement off.

What exactly was tested

Raw sequence and filler

Memory was populated from earlier OCR events, including plates, signs, short replies and faulty fragments. This is not a clean-story-only test. Old Czech translations never entered memory.

Selection and pilot

64 jobs in 16 four-job windows spread through the original session, plus 24 authored scenes. The separate pilot had six cases. CUNI had two pilot instructions; a stricter ban on adding text did not solve the problem.

Timestamped transcript

An exploratory follow-up on the same target lines: stitches adjacent growing OCR captions, keeps repetition after another turn, adds start/end times and a candidate segment after a gap. Sends up to six turns from the last 60 seconds. Temporal proximity does not prove a shared speaker or topic.

What the comparison does not isolate

The timestamped variant also changes stitching and selection, not just time numbers. CUNI and Luna ran it after the main run; both Gemmas interleave it with other arms. Synthetic cases also differ in supplied verified profiles. These results do not isolate the effect of timestamps alone.

Laptop and server

Laptop: Intel i5-13420H, 32 GB RAM, RTX 4050 Laptop 6 GB, Windows 11. CUNI fully on GPU; TranslateGemma 12B uses GPU and RAM. Server: Ubuntu, RTX 3090 24 GB, Gemma 4 26B A4B Heretic Q5_K_S via llama.cpp. It is a different model from TranslateGemma.

Latency and cost

One local model at a time; warm-up excluded. An Internet download could run concurrently. API latency and outputs can vary even at temperature zero. Luna cost is calculated from returned tokens: $0.10 input / $0.01 cached / $0.50 output per million tokens; no paid assessment.

Rubric

0–4 for meaning preservation and readability: 4 no material error, 3 minor shift/awkwardness, 2 important change or added content, 1 main meaning lost or long repetition, 0 different/missing line. Score /100 = 25 × mean. Unknown speaker gender is not graded. Five corrupted/already-Czech inputs are excluded from scoring, with all outputs retained.
