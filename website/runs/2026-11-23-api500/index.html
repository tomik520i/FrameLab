Co z toho vychází

CUNI má v této sadě největší podobnost s lidskou referencí (chrF++), API dostalo od anonymizovaného AI posuzovatele nejvyšší průměr za význam a přirozenost. To nejsou totožná měřítka a posuzovatel je od stejného dodavatele jako API kandidát. CUNI je zde přesvědčivá místní volba pro EN → CS; širší jazyková nabídka TranslateGemma sama nezaručuje lepší češtinu. API šetří místní výpočet překladu, ale na tomto notebooku čekalo déle než oba GPU modely.

Konkrétní chyby najdeš přes hledání ID: w500-002 — CPU ztratil „nemrtvé“, Gemma vytvořila gramaticky vadné přání, CUNI a API zachovaly význam. w500-032 — i API selhalo: „I will put an end…“ změnilo na rozkaz „skoncuj“; CUNI tuto repliku zvládlo. w500-026 ukazuje subjektivitu skóre: posuzovatel API strhl bod za vynechání nejistoty „may“, přestože česká věta zní přirozeně.
