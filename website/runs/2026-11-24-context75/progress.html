Completed runs are not a quality score. Wrong, delayed and missing translations remain in the evidence. Updates arrive between runs, approximately once a minute. Codex reviews the outputs directly; no paid judging calls.

What is actually running

Identical video pixels for all four variants: ordinary OCR, filtering, translation, memory selected by that same model, and the caption actually rendered. NVIDIA VFG 2× and the experimental NR enhancer are enabled. Three unmodified framebuffer exports per run document the application output.

Each scene contains initial context, an ambiguous line, eight interruptions including a licence plate and a UI label, a return to the line, and a topic change. These are authored diagnostic scenes over gameplay, not actual GTA dialogue or representative average game accuracy. The 75 language cases use 50 distinct input videos; some semantic families repeat across languages.

Laptop: RTX 4050 Laptop, i5-13420H, 32 GB RAM. Gemma runs separately on a LAN server with an RTX 3090. Luna is a paid API. This does not constitute a new public installation package.
