What adds up — and what needs context

10 original files / 358,079,129 bytes. 10,727 telemetry rows, 658,481 frame rows. Zero malformed event rows and zero logger-dropped rows. One model-ready event after 18.899 s; no logged model retry or OCR/translation runtime error. Six translated captions were not displayed.

The final OCR completion counter (32,850) differs from logged completed jobs (32,844). The code increments the counter before discarding a result invalidated by a subtitle reset; nine resets occurred. This explains a possible six-result gap, but those suppressed events cannot be individually recovered. We use the 32,844 actual events for latency. Submit events (34,963) and the last 1 Hz submit counter (34,961) also have different observation boundaries. Full counters and reconciliation are in the methods.
