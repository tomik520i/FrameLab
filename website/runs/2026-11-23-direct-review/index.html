Jak číst skóre a jeho omezení

Pořadí anonymních kandidátů A–D bylo promíchané zvlášť pro každou repliku. Styl mohl prozradit původ modelu a hodnotitel znal dřívější obecné závěry. Jde o asistenta Codex od OpenAI; jeden kandidát je od stejného dodavatele. Původní placené skóre nebylo použité k přidělení těchto bodů a zůstává zvlášť v archivu.

  • Význam: 4 = zachován; 3 = menší ztráta nebo posun; 2 = podstatná chyba; 1 = převážně nesprávně; 0 = chybí nebo nesouvisí.
  • Čeština: 4 = přirozená; 3 = drobné neobratnosti; 2 = více gramatických problémů; 1 = těžko srozumitelná; 0 = chybí nebo není česká.
  • Rozhoduje anglický originál. Česká reference je pomůcka; přijatelné synonymum nebo rod, který angličtina neurčuje, není sám o sobě chyba. Případy 042 a 437 dokládají chyby reference.
  • 500 různých položek z fantasy hry Battle for Wesnoth, ne 500 nezávislých žánrů. Některé repliky jsou si podobné; modely mohly veřejná data vidět při trénování. Výsledky neprokazují kvalitu ostatních jazyků nebo OCR.
  • Časy pocházejí z původního textového testu na i5-13420H / RTX 4050 Laptop 6 GiB. OCR, FG a enhancer byly vypnuté. Lokální modely běžely postupně, API souběžně s lokálním testem. Nejde o latenci titulku ve hře.
  • Starší testy Hy-MT Q8 a dalších kvantizací používaly jinou sadu 300 položek. Do tohoto pořadí se nepřimíchávají. Srovnání CUDA/Vulkan měří jinou, malou sadu a výkon; nemění zde hodnocené výstupy.
  • API případ 161 selhal. Pozdější úspěšný diagnostický pokus jej nenahrazuje. U každého skóre lze dohledat skutečný původní výstup.
